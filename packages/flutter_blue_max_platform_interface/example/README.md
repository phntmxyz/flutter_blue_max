# Example

This package defines the platform interface of flutter_blue_max and is meant for implementers of platform packages.

Use [flutter_blue_max](https://pub.dev/packages/flutter_blue_max) in your app.
It picks this implementation automatically on every platform.
See its [example app](https://github.com/phntmxyz/flutter_blue_max/tree/main/packages/flutter_blue_max/example) for a complete demo.
