# Example

This package is the web implementation of flutter_blue_max and is not meant to be used directly.

Use [flutter_blue_max](https://pub.dev/packages/flutter_blue_max) in your app.
It picks this implementation automatically on the web.
See its [example app](https://github.com/phntmxyz/flutter_blue_max/tree/master/packages/flutter_blue_max/example) for a complete demo.
